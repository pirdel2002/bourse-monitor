# Bourse Monitor

سامانه شخصی پایش شرط‌های بورس تهران و ارسال هشدار تلگرام. این برنامه سفارش واقعی ثبت نمی‌کند.

## قابلیت‌ها

- تعریف شرط به زبان فارسی
- تعریف بصری قواعد و گروه‌های تو‌در‌توی `AND` و `OR`
- جست‌وجوی نماد از فهرست محلی
- قواعد قیمت، عبور، تثبیت، محدوده، برگشت، قدرت خریدار، نسبت تقاضا و عرضه و صف
- زمان شروع، پایان و فاصله بررسی مستقل برای هر پایش
- اقدامات خرید، میانگین کم‌کردن، فروش در حد زیان و فروش برای سیو سود
- درج تعداد، قیمت پیشنهادی و مبلغ تقریبی در هشدار تلگرام
- جلوگیری از اعلان تکراری؛ اعلان هنگام تغییر حالت به «فعال»
- ذخیره تاریخچه، Snapshot و مصرف API در SQLite با WAL
- محدودیت پایدار روزانه و پنج‌دقیقه‌ای برای هر API
- اشتراک یک پاسخ `AllSymbols` بین تمام شرط‌های سررسیدشده
- Docker Compose، Healthcheck و نصب تک‌خطی روی Ubuntu VPS
- رابط Responsive با فونت وزیر، صفحه ورود و تب‌های پایش، آرشیو، پیام‌ها و پرونده نماد
- ورود گروهی پایش‌ها با Paste یا فایل TXT/JSON
- چند ربات تلگرام و چند کلید BRSAPI با حالت‌های اتوماتیک، بالانس و فالبک
- Backup و Restore رمزگذاری‌شده برای مهاجرت کامل سرور
- بازیابی رمز مدیر با کد یک‌بارمصرف تلگرام

## نصب تک‌خطی روی VPS

دستور زیر برنامه را در `/opt/bourse-monitor` نصب می‌کند و فقط روی `127.0.0.1:3000` در دسترس قرار می‌دهد:

```bash
curl -fsSL https://raw.githubusercontent.com/pirdel2002/bourse-monitor/main/install.sh | sudo bash
```

اسکریپت کلید BRSAPI، توکن ربات و Chat ID را در ترمینال درخواست می‌کند. مقادیر محرمانه نمایش داده نمی‌شوند و وارد History شل نیز نمی‌شوند. سپس یک `ADMIN_TOKEN` تصادفی تولید و در پایان فقط یک‌بار نمایش می‌دهد. برای نصب خودکار در CI می‌توانید متغیرها را همراه `NONINTERACTIVE=1` ارسال کنید.

برای بازکردن امن داشبورد از کامپیوتر خود:

```bash
ssh -L 3000:127.0.0.1:3000 USER@VPS_IP
```

سپس `http://127.0.0.1:3000` را باز کنید و توکن مدیریت را وارد کنید.

برای انتشار مستقیم داشبورد روی اینترنت، ابتدا HTTPS و Reverse Proxy نصب کنید. قراردادن داشبورد روی HTTP عمومی توصیه نمی‌شود.

## دسترسی عمومی موبایل بدون پورت ۸۰ و ۴۴۳

برنامه روی `127.0.0.1:3000` باقی می‌ماند. اگر پورت‌های ۸۰ و ۴۴۳ سرور در اختیار VPN هستند، یک Cloudflare Tunnel بسازید و Public Hostname آن را به سرویس زیر متصل کنید:

```text
http://app:3000
```

توکن Tunnel را هنگام اجرای `install.sh` وارد کنید. نصب‌کننده فایل `compose.tunnel.yaml` را خودکار فعال می‌کند. در این حالت هیچ پورت عمومی جدیدی باز نمی‌شود و موبایل از HTTPS دامنه استفاده می‌کند.

اجرای دستی Tunnel:

```bash
docker compose -f compose.yaml -f compose.tunnel.yaml --env-file .env up -d --build
```

پورت `3000` را با HTTP خام روی اینترنت منتشر نکنید. رمز ورود، کلید API و فایل پشتیبان از این مسیر عبور می‌کنند.

## اجرای محلی

```bash
cp .env.example .env
# ADMIN_TOKEN را تغییر دهید
docker compose up -d --build
```

حالت پیش‌فرض `mock` است و سهمیه واقعی مصرف نمی‌کند. برای BRSAPI:

```env
DATA_PROVIDER=brsapi
BRS_API_KEY=...
BRS_USER_AGENT=Mozilla/5.0 ... Chrome/... Safari/537.36
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

## محدودیت API

محدودیت‌ها فقط تنظیم ظاهری نیستند. مصرف هر endpoint پیش از درخواست در تراکنش دیتابیس رزرو می‌شود. ری‌استارت برنامه شمارنده را صفر نمی‌کند.

پیش‌فرض‌ها:

| API | روزانه | هر پنج دقیقه |
|---|---:|---:|
| AllSymbols | 100 | 2 |
| Symbol | 10 | 2 |
| Index | 100 | 2 |
| Candlestick | 10 | 2 |
| مجموع همه APIها | — | 300 |

مقادیر را دقیقاً مطابق بسته BRSAPI خود در `.env` تنظیم کنید. `MARKET_CACHE_SECONDS=150` باعث می‌شود چند شرط هم‌زمان فقط یک درخواست `AllSymbols` مصرف کنند. جست‌وجوی نماد نیز از دیتابیس محلی انجام می‌شود و به‌ازای هر حرف API را فراخوانی نمی‌کند.

اگر سهمیه تمام شود، برنامه درخواست را ارسال نمی‌کند و خطای `API_QUOTA_EXCEEDED` ثبت می‌شود.

تمام درخواست‌های BRSAPI با `User-Agent` صریح و قابل تنظیم ارسال می‌شوند. مقدار پیش‌فرض مشابه Chrome دسکتاپ است. آن را حذف نکنید؛ درخواست بدون `User-Agent` معتبر ممکن است باعث مسدودی IP سرور شود.

## شرط نوشتاری

نمونه‌های پشتیبانی‌شده:

```text
تثبیت بالای ۳۳۰۰ و قدرت خریدار بیشتر از ۱.۳
جمع شدن صف فروش و عبور به بالای ۱۴۸۵
برگشت از محدوده ۱۲۶۰۰ تا ۱۲۹۰۰
قیمت کمتر از ۲۴۰۰۰ یا تثبیت پایین‌تر از ۲۴۵۰۰
```

تبدیل متن قطعی و محدود است. اگر عبارت شناخته نشود، برنامه آن را حدس نمی‌زند و از کاربر می‌خواهد از قاعده‌ساز استفاده کند.

## معنای قواعد زمانی

- `تثبیت بالای`: پیش‌فرض سه نمونه متوالی بالای سطح
- `عبور به بالا`: نمونه قبلی زیر یا مساوی سطح و نمونه جدید بالای سطح
- `جمع‌شدن صف فروش`: وجود صف در یک نمونه قبلی و صفرشدن آن در نمونه جدید
- `برگشت از محدوده`: ثبت قیمت در محدوده و سپس خروج از سقف محدوده

این تعریف‌ها قابل تست هستند. عبارت مبهمی مانند «تقاضای خوب» به‌تنهایی قاعده محسوب نمی‌شود. باید با قدرت خریدار یا نسبت تقاضا به عرضه تعریف شود.

## پیام تلگرام

پیام فعال‌شدن شرط شامل این موارد است:

- نماد و نوع اقدام
- تعداد سهم
- قیمت پیشنهادی به ریال
- مبلغ تقریبی به تومان
- آخرین قیمت و قیمت پایانی
- قدرت خریدار و نسبت تقاضا به عرضه
- شواهد هر قاعده

## ورود گروهی پایش‌ها

در تب «ورود گروهی»، متن را Paste کنید یا فایل UTF-8 با پسوند TXT/JSON بارگذاری کنید. پایش‌ها با خط `---` از هم جدا می‌شوند:

```text
عنوان: خرید فولاد
نماد: فولاد
اقدام: خرید
تعداد: 10000
قیمت پیشنهادی: 3350
شروع: اکنون
پایان: پایان امروز
فاصله بررسی: 10
شرط: قیمت بیشتر از 3300
---
عنوان: حد زیان وبملت
نماد: وبملت
اقدام: حد زیان
تعداد: 5000
قیمت پیشنهادی: 2400
شروع: فردا 09:30
پایان: 2026-09-30 12:30
فاصله بررسی: 5
شرط: قیمت کمتر از 2400
```

زمان‌های بدون منطقه زمانی، زمان ایران محسوب می‌شوند. همه زمان‌های داخلی به UTC ذخیره و در رابط فقط با `Asia/Tehran` نمایش داده می‌شوند؛ بنابراین محل سرور روی زمان‌بندی اثر ندارد.

## پشتیبان‌گیری و مهاجرت

تب «پشتیبان و بازیابی» یک فایل `.bmon` می‌سازد. فایل با AES-256-GCM و گذرواژه کاربر رمزگذاری می‌شود و شامل پایش‌ها، رویدادها، نمادها، تنظیمات اتصال، ربات‌ها، کلیدها و رمز مدیر است. برای مهاجرت، نسخه تازه مخزن را روی سرور مقصد نصب کنید و فایل را از همان تب Restore کنید.

گذرواژه Backup داخل فایل یا سرور ذخیره نمی‌شود. بدون آن بازیابی ممکن نیست.

## نگهداری

```bash
cd /opt/bourse-monitor
sudo docker compose logs -f --tail=200
sudo docker compose pull
sudo git pull --ff-only
sudo docker compose up -d --build
```

پشتیبان‌گیری:

```bash
sudo cp /opt/bourse-monitor/data/monitor.db /root/monitor-$(date +%F).db
```

## محدودیت‌های نسخه ۱

- تشخیص صف به وجود داده معتبر ردیف سفارش در پاسخ BRSAPI وابسته است.
- تقویم تعطیلات رسمی هنوز خودکار نیست؛ بازه پایش را کاربر تعیین می‌کند.
- متن فارسی آزاد به همه شکل‌های نگارشی تبدیل نمی‌شود.
- معامله خودکار عمداً وجود ندارد.

پیش از استفاده با پول واقعی، خروجی را در حالت کاغذی بررسی کنید.
